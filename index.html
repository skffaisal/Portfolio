GPS logistics lock

Winger IT Solutions — container locks on vehicles in transit

Transport containers used to open with a physical key, which means the key can be copied, lost, or lent. I built the FastAPI services that replaced it: a driver requests access, the backend authorises it and issues a one-time code that is only valid for sixty seconds.

I owned the authentication layer, working alongside the team wiring up the GPS/GNSS hardware and the 4G link back to the server.

60svalidity window, so a leaked code is worthless by the time it travels

On-prem email validation pipeline

Winger IT Solutions — internal, replacing a paid API

Every lead list had to be validated through a third-party service that billed per check. I designed and hosted an eight-stage pipeline that does the same work on our own hardware — syntax, DNS and MX lookups, disposable and role-address detection, catch-all handling, an SMTP probe, and a final deliverability score.

It shipped, it runs on-prem, and the subscription was cancelled.
